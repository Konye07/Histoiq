# Historiq

A Kotlin Multiplatform + Compose Multiplatform history-trivia app — Android and iOS from one
codebase, sharing the same Material3 UI and the same Supabase backend. Six daily quiz games test
different kinds of historical knowledge, each playable once per day and resumable mid-round.
Accounts, friends, stats, and the daily quizzes themselves are backed by Supabase, so every device
sees the exact same questions on the same date, and real friends can see each other's scores.

## The six games

| Role name | Mechanic |
|---|---|
| Annalist | Guess the year of a historical event or battle |
| Herald | Guess a battle's casualty count (scored as a multiplier — closer is better) |
| Officer-of-Arms | Recolor a historical flag's dominant color to match the original |
| Cosmographer | Pick the larger of two countries by peak territorial size, sudden-death |
| Chronicler | True/false historical statements, sudden-death |
| Chancellor | Tap a battle's location on a blank world map |

## Building

**Android**: requires JDK 17+ and the Android SDK. The Gradle wrapper is checked in, so no separate
Gradle install is needed:

```
./gradlew :composeApp:assembleDebug
```

(`gradlew.bat` on Windows.) Open the project in Android Studio for the usual run/debug workflow —
pick the `composeApp` run configuration, not `app` (that module no longer exists). You'll also need
a `local.properties` with `SUPABASE_URL` and `SUPABASE_ANON_KEY` set (see `CLAUDE.md`) — without
them the app builds but can't reach the backend.

**iOS**: requires a Mac with Xcode. `iosApp/project.yml` is the source of truth for the Xcode
project (generated by [XcodeGen](https://github.com/yonaskolb/XcodeGen), not committed):

```
cd iosApp && xcodegen generate && open iosApp.xcodeproj
```

Build `composeApp`'s Kotlin framework first (`./gradlew :composeApp:linkDebugFrameworkIosSimulatorArm64`
for the simulator) before building/running from Xcode.

## Project layout

- `composeApp/src/commonMain/kotlin/com/konye/historiq/` — shared Kotlin source (screens, data layer,
  navigation, string tables) compiled for both platforms.
  - `Features/Play/` — one package per game, plus `Features/Play/Shared/` for cross-game UI
    (results header, guess-distribution axis, hint/ad dialog).
  - `Data/Quiz/` — data classes, Supabase-backed loaders (`QuizDataSource.kt`), scoring
    (`ScoringUtils.kt`), the shared daily-quiz assignment (`DailyQuizRepository.kt`), and per-account
    progress/stats/history/leaderboard stores.
  - `Data/Account/` — anonymous-auth-backed accounts (`AccountRepository.kt`).
  - `Data/Social/` — real friend requests/leaderboard (`FriendsRepository.kt`, `FriendsStore.kt`).
  - `Data/Remote/` — the single Supabase client (`SupabaseClient.kt`).
  - `Core/Theme/` — the fixed color palette and per-game `ColorScheme` generation.
  - `Core/Localization/` — the runtime language-switching string-table system.
- `composeApp/src/androidMain/` / `composeApp/src/iosMain/` — real per-platform implementations
  (haptics, sound, share, notifications) behind `expect`/`actual`; `androidMain` is also the
  installable Android app itself (manifest, launcher icons).
- `composeApp/src/commonMain/composeResources/files/images/` — flag/event artwork (sourced from
  Wikimedia Commons under verified public-domain or CC licenses) plus the world map used by
  Chancellor; stays bundled in the app rather than moving to Supabase Storage.
- `iosApp/` — the SwiftUI shell hosting Compose on iOS; see "Building" above.
- `seed-data/` (repo root) — the question banks' original JSON, not shipped in the app; see
  `CLAUDE.md` for the live Postgres schema each game's field-level structure now lives in.

See `CLAUDE.md` for the full Supabase schema/architecture and build-toolchain notes.

## Status

CI (GitHub Actions) builds Android and runs a real iOS Kotlin/Native compile + Xcode build on every
push. Guest mode (no account) is the only remaining local-only/mocked path, by design — everything
else (auth, friends, daily quizzes, stats, score history, leaderboards) is real and backed by
Supabase.
